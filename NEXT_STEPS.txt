================================================================================
TROUBLESHOOTING
================================================================================

If marker_single fails:
  - Ensure marker-pdf is installed: pip list | grep marker
  - Check if marker_single is in PATH: which marker_single
  - Run with -v for detailed logs

If RTDETR detection fails:
  - Check if ultralytics installed: pip list | grep ultralytics
  - Should fallback to full frame gracefully
  - Check logs for "RTDETR detection failed"

If LibreOffice conversion fails:
  - Ensure LibreOffice installed: which libreoffice
  - Check if PPTX file is valid: file slides.pptx
  - Run with -v for detailed error

If PDF validation fails:
  - Check frame count vs PDF page count match
  - Ensure PyPDF2 installed: pip list | grep PyPDF2

================================================================================
KEY IMPLEMENTATION DETAILS
================================================================================

CLI Arguments:
  --cropped-slide         -> Sets args.cropped_slide to "auto" or ROI string
  --ppt /path/file.pdf    -> Sets args.ppt to file path
  --no-ocr                -> Sets args.no_ocr = True
  --no-clean              -> Sets args.no_clean = True

Routing Logic (in handle_ppt_command):
  if args.ppt:                    → TYPE 3 (ppt_slide.execute_ppt_method)
  elif args.cropped_slide:        → TYPE 2 (cropped_slide.execute_cropped_slide_method)
  else:                           → TYPE 1 (in-place implementation)

Base64 Format:
  <img src="data:image/png;base64,iVBORw0KGgoAAAANS..." />

Clean Phase:
  Removes: ### **HH:MM:SS** headers and ![slide](/path/to/image.png)
  Keeps: <img src="data:image/png;base64,..." /> and text content

Output Files:
  - {base_name}_combine.md (always)
  - {base_name}_combine_clean.md (unless --no-clean)
  - {base_name}_cropped-slide/ (for Type 2 only)
  - Intermediate: _slides.md, _cropped-slide.md, _ppt.md
